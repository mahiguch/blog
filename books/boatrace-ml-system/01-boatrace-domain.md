## この章で学ぶこと

| 観点 | 内容 |
| --- | --- |
| ML(予測問題として) | 6 艇のレースを「3 連単 120 通りの確率分布を、締切前に手に入る情報だけから推定する問題」として定式化する。配当の偏りが、なぜ的中率だけでは評価できないかを決める |
| システム(データとして) | 枠番とコースの違いと daily / realtime の 2 状態、ST の欠損表現、決まり手、スリット隊形、場とレース番号の個性。以後の章で扱う CSV の列が何を表すかを、ここで押さえる |

本書はボートレースの知識を前提にしません。この章では、予測モデルを作るうえで必要な最小限の
ドメイン知識を、公開 CSV から実測した数値と一緒に説明します。数値は特に断りがない限り
boatracecsv の設計書に記録された **2026 年 8 月時点**の実測値で、母数 n を添えます。

## 1. レースの基本構造

### 1.1 予測問題としての定式化

最初に、本書が解こうとしている問題を予測問題の言葉で書いておきます。

- 1 レースには **6 艇**が出走します。艇には 1〜6 の番号(艇番)が付いています
- 本書が扱う舟券は **3 連単**で、1 着・2 着・3 着の艇番を順番どおりに当てます。
  組み合わせは 6 × 5 × 4 = **120 通り**です
- 使ってよい情報は**締切前に手に入るもの**だけです。出走表(選手・モーターの成績)、
  締切数分前に公開される直前情報(進入コースとスタート展示、展示タイム、気象)がそれにあたり、
  本番のスタートタイミングや決まり手といった**レース後にしか分からない情報は使えません**

つまり、1 レースを「120 個のクラスを持つ多クラス分類」と見なし、締切前の特徴量から
120 通りの確率分布を推定する、というのが本書の問題設定です。予測した分布から
「どの出目を何点買うか」を決める工程は第 8 章、予測の良し悪しを測る指標は第 9 章で扱います。

この定式化には 2 つの含みがあります。

1. **正解は 1 レースに 1 つ**しかありません。120 通りのうち 1 つだけが的中で、
   残り 119 通りは外れです。当てずっぽうの的中率は 1/120 ≒ 0.8% です
2. **締切前の情報しか使えない**という制約が、あとで効いてきます。第 19 章では
   「レース後の情報(実測スタートタイミング)なら結果をよく説明できるのに、
   締切前にはそれを再現できない」という壁にぶつかります

### 1.2 6 艇・12 レース・24 場

- 1 レースは 6 艇で争われます
- 1 日 1 場あたり **12 レース**(1R〜12R)が行われます
- 開催場は全国に **24 場**あり、`01` 桐生 から `24` 大村 まで 2 桁のコードが振られています。
  fun-site ではこの 24 場のマスタを `STADIUMS` として持ち、コードと名前を相互に引けるようにしています

```ts:packages/shared/src/constants/stadiums.ts
export const STADIUMS: readonly Stadium[] = [
  { id: "01", name: "桐生", prefecture: "群馬県" },
  { id: "02", name: "戸田", prefecture: "埼玉県" },
  { id: "03", name: "江戸川", prefecture: "東京都" },
  // ...(中略)...
  { id: "24", name: "大村", prefecture: "長崎県" },
] as const;

export const getStadiumById = (id: string): Stadium | undefined =>
  STADIUMS.find((s) => s.id === id);
```

公開 CSV では、この 3 つを連結した **12 桁のレースコード**(`YYYYMMDD` + 場コード 2 桁 + レース番号 2 桁。
例: `202608011001` は 2026-08-01 の三国 1R)が全ファイル共通の主キーになります。
出走表・直前情報・結果・払戻金はすべてこのキーで JOIN できます(第 2 章)。

選手には **A1 / A2 / B1 / B2** の 4 段階の級別があり、A1 が最上位です。出走表には
級別のほかに全国勝率・当地勝率・モーターやボートの 2 連対率・全国平均 ST などが載っています。
これらが第 4 章以降で特徴量になります。

### 1.3 舟券の券種と 3 連単

舟券には複数の券種があり、当てる対象と組み合わせ数が異なります。

| 券種 | 当てるもの | 組み合わせ数 |
| --- | --- | ---: |
| 単勝 | 1 着の艇 | 6 |
| 複勝 | 2 着までに入る艇 | 6 |
| 2 連単 | 1・2 着を順番どおり | 30 |
| 2 連複 | 1・2 着を順不同 | 15 |
| 拡連複 | 3 着までに入る 2 艇を順不同 | 15 |
| 3 連複 | 1〜3 着を順不同 | 20 |
| **3 連単** | **1〜3 着を順番どおり** | **120** |

組み合わせ数は、boatracecsv が配信するオッズ CSV の列数そのものです(`od3` が 3 連単 120 列、
`od1` が 3 連複 20 列と拡連複 15 列、`od2` が 2 連単 30 列と 2 連複 15 列)。

本書が 3 連単を対象にするのは、組み合わせが最も多く、次の 1.4 で見るように配当の幅が
最も大きいためです。的中率と配当のトレードオフが最も鮮明に出る券種で、
予測モデルの差が結果に表れやすいと考えられます。

### 1.4 配当の構造

配当(払戻金)は 100 円あたりの金額で表します。10,000 円以上、つまり 100 倍以上の配当を
**万舟(まんしゅう)** と呼びます。boatracecsv が 2025-11-01〜2026-08-11 の払戻金 CSV
**42,090 レース**を集計した 3 連単配当の分布は次のとおりです。

| 3 連単配当 | レース割合 | 払戻総額に占める割合 |
| --- | ---: | ---: |
| 〜1,000 円 | 19.2% | 1.9% |
| 1,000〜3,000 円 | 36.9% | 9.3% |
| 3,000〜10,000 円 | 27.5% | 21.1% |
| 10,000〜30,000 円 | 11.7% | 27.3% |
| 30,000〜100,000 円 | 4.0% | 27.0% |
| 100,000 円〜 | 0.6% | 13.3% |

万舟(10,000 円以上)は **レースの 16.3%** にすぎませんが、**払戻総額の 67.6%** を占めています。
逆に、レースの過半(56.1%)を占める 3,000 円未満の配当は、払戻総額の 11.2% しかありません。

この偏りが、本書の評価指標の選び方を決めています。的中率だけを上げても、当たるのが
低配当のレースばかりなら回収率は伸びません。一方で高配当を狙うと的中率は下がります。
同じデータで「毎レース人気 k 位の 3 連単を 1 点買う」戦略の回収率を測ると、
人気 1〜3 位で 76.8%(的中率 26.4%)、人気 81〜120 位では **43.6%**(的中率 2.3%)まで落ちます
(n = 42,090)。控除率 25% はどの人気帯でも同じなので、この落ち方は投票者が人気薄を
買いすぎているぶんの損です。「穴に寄ること自体が回収率にマイナス」という構造を、
第 20 章で favourite-longshot bias として扱います。

## 2. 枠番とコースは違う

### 2.1 枠番・コース・進入

艇番(枠番)は出走表で決まっている 1〜6 の番号です。一方、スタート時に艇が並ぶ位置を
**コース**と呼び、内側から 1 コース〜6 コースです。スタートまでの間に各艇がコースを
取り合うので、枠番とコースは同じとは限りません。

- 枠番どおりにコースに入ることを**枠なり**と呼びます
- 外の枠の艇が内側のコースを取りにいくことを**前付け**と呼びます

実際にはほとんどが枠なりで、1 号艇が 1 コースに入る割合は **約 98%** です(fun-site
`docs/domain.md` の目安値)。ただし残りの数 % で枠番とコースがずれ、そのレースでは
「1 号艇」の成績と「1 コース」の成績が別物になります。

内側のコースほど有利で、1 コース(イン)の 1 着率が突出して高いのがボートレースの最大の特徴です。
本書のモデルは、特徴量の多くを**艇番ではなくコース**に紐付けて計算します
(例: 場 × 季節 × コースの強度テーブルを引く枠番 pt、コース別に係数を持つ気象 pt。第 4 章)。
したがって「その艇がどのコースに入るか」を、締切前にどう決めるかが問題になります。

### 2.2 daily と realtime の 2 状態

進入コースが確定するのは本番のスタート直前ですが、締切の約 5 分前から公開される
**スタート展示**(本番と同じ手順で行う試走)で、各艇がどのコースに入ったかと
そのときのスタートタイミングが分かります。boatracecsv はこれを `previews/stt` として
取得しています。

そこで本書のモデルは、1 レースにつき 2 回計算します。

| 状態 | 計算のタイミング | 進入コース | 展示・気象の成分 |
| --- | --- | --- | --- |
| `daily` | 朝、出走表が出た時点 | 枠なりと仮定(艇番 = コース) | まだ無いので中立値 |
| `realtime` | スタート展示の取得後(締切の数分前) | 展示で実際に入ったコース | 実測値で計算 |

`daily` は「直前情報が無い状態での仮の評価」、`realtime` は「締切直前の情報で引き直した評価」です。
強さ pt の CSV には `状態` 列があり、この 2 値のどちらかが入っています。
朝の買い目と直前の買い目が変わる主因は、コースの引き直しと展示・気象成分の反映です。

この 2 状態は、以後すべての章に出てきます。収集(第 3 章)では realtime 行をいつ・何回
取りにいくかの設計になり、配信(第 13 章・第 14 章)では「stt 未取得のレースは進入コースを
枠番で仮表示する」というフォールバックになります。

:::message
スタート展示の進入コースと本番の進入コースも、完全には一致しません。boatracecsv の
実測(2026 年 8 月時点)では、1 着艇のコースが展示と本番で一致する割合は 96.8%、
6 艇すべての進入が一致する割合は 87.9% です。締切前に使える最善の情報が展示進入なので、
本書のモデルはすべて展示進入を基準にします。
:::

## 3. ST(スタートタイミング)

### 3.1 フライングスタートと ST

ボートレースはフライングスタート制です。艇は助走をつけて走りながらスタートラインを通過し、
**大時計が 0 秒を指した瞬間からどれだけ遅れて通過したか**が **ST(スタートタイミング)** です。
ST は艇の**舳先(へさき)** がスタートラインを通過した時刻で記録されます。

- ST が小さいほど早いスタートです
- 0 秒より前に通過するとフライング(F)で、着順の代わりに `F` と記録されます。結果 CSV の ST は
  負の値(例 `-0.02`)になります
- 大きく遅れると出遅れ(L)です。結果 CSV には L 専用のマークは無く、大きな ST(〜0.99)として
  数値で記録されます

boatracecsv の実測では、本番 ST の平均は 0.158 秒、スタート展示 ST の平均は 0.074 秒です
(2025-11-01〜2026-08-09、41,776 レース)。展示は本番より約 0.08 秒早いだけでなく、
両者の相関は **0.05** 程度しかありません。展示 ST は「その日の勘」の 1 サンプルであって、
本番でどこまで踏み込むかとは別物です。この事実は第 18 章(ST 推定)と第 19 章(スリット展開)の
出発点になります。

ST の差は距離に換算できます。スリット付近の艇速を約 50km/h = 13.9m/s と置くと、
ST 差 0.01 秒 ≒ 0.14m、艇長 3m の 1 艇身 ≒ ST 差 0.216 秒です(`slit_tenkai.md` §1)。
艇速をどう置くかで換算は変わり、第 15 章のスタート予想図ではスリット付近 80km/h 換算
(1 艇身 = 0.135 秒)を使います。

### 3.2 全国平均 ST の `0.00` は「実績なし」

出走表には選手ごとの**全国平均 ST** が載っており、締切前に使える ST の情報はほぼこれだけです
(実測との相関は 0.21〜0.25。展示 ST の 0.05 よりは高い)。

ここに 1 つ落とし穴があります。全国平均 ST が `0.00` の選手は「最速」ではなく、
新人や長期離脱明けなどで**公表実績が無い**選手です。これを数値のまま使うと、
0.00 が「最速スタート」として扱われてしまいます。実際に fun-site の 1 マーク走行距離の計算では、
描画側だけ 0.25 秒に補完し、距離計算側は 0.00 のまま最速扱いになっていた時期がありました。
現在は `NO_RECORD_ST_FALLBACK`(0.25 秒)への補完に統一されています。
この不整合の発見と修正は第 18 章で扱います。

:::message alert
公開 CSV を自分で使うときも、全国平均 ST の `0.00` は NaN に変換してから使ってください。
結果 CSV の ST についても、`-`(欠測)の行が 1.1% あります。
:::

## 4. 決まり手とスリット隊形

### 4.1 1 マークと決まり手

スタート後、6 艇は最初のターンマーク(**1 マーク**)に向かいます。ボートレースでは
この 1 マークの攻防でほぼ勝敗が決まります。どのように 1 着を取ったかを**決まり手**と呼び、
6 種類に分類されます。

| 決まり手 | 説明 | 起きやすい条件(定説) |
| --- | --- | --- |
| 逃げ | 1 コースがそのまま先行して逃げ切る | 1 コースが A1 級、モーター好調、追い風 |
| 差し | 内側から 2〜3 コースが差す | 1 コースがターンで膨らんだ場合、2 コースの差し巧者 |
| まくり | 外側(主に 3〜4 コース)から一気にまくる | カド(4 コース)のスタートが早い、向かい風 |
| まくり差し | 外からまくりつつ内を差す | 高度な技術が必要、A1 級の実力者に多い |
| 抜き | 2 周目以降に逆転 | モーター性能差が大きい場合 |
| 恵まれ | 前の艇の失敗で繰り上がり | 転覆・落水・エンスト |

![1 マークでの決まり手 4 種の軌道](/images/boatrace-ml-system/01-kimarite.png)
<!-- 図: 1 マーク(ブイ)を上から見た図。1 コースが内側を回る「逃げ」、2 コースがその内側に入る「差し」、4 コースが外から前に出て被せる「まくり」、外から回りつつ内に切り込む「まくり差し」の 4 本の軌道を艇色(白・黒・青・赤など)で描く -->

決まり手は結果 CSV(`results/realtime`)の `決まり手` 列に入ります。値は `逃　げ` `差　し` `抜　き` のように
**全角スペースで 3 文字に揃えられている**ので、文字列比較をするときは注意してください。

### 4.2 決まり手は穴そのもの

決まり手ごとに配当を集計すると、次のようになります(2026 年 8 月時点、n = 42,010)。

| 決まり手 | 割合 | 平均配当 | 中央値 | 万舟率 | 平均人気 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 逃げ | 52.5% | 2,565 円 | 1,430 円 | 3.6% | 8.1 |
| 差し | 11.9% | 10,569 円 | 4,790 円 | 26.9% | 25.0 |
| まくり | 15.6% | 12,374 円 | 6,170 円 | 33.4% | 28.9 |
| まくり差し | 11.8% | 14,728 円 | 6,500 円 | 36.7% | 31.2 |
| 抜き | 6.2% | 10,689 円 | 3,730 円 | 24.3% | 22.9 |
| 恵まれ | 0.7% | 10,657 円 | 2,470 円 | 20.4% | 18.7 |

レースの半分強は逃げで決まり、その平均配当は 2,565 円・万舟率 3.6% です。
これに対し、まくりは平均 12,374 円・万舟率 33.4%、まくり差しは 14,728 円・36.7% で、
**逃げか否かで配当が 4〜6 倍違います**。「逃げ以外を当てる」ことと「穴を当てる」ことが
ほぼ同義になっているため、第 20 章では決まり手そのものを予測ターゲットにします。

決まり手と 1 着コースの組み合わせにも構造があります。逃げは定義上 1 コースからしか出ず、
まくり差しは 2 コースからは出ません。決まり手 × 1 着コースの表(全レースに対する %)を見ると、
逃げ 1 コースが 53.32% で、差しは 2 コース(8.07%)、まくりは 3 コース(5.09%)と 4 コース(4.98%)、
まくり差しは 3 コース(4.78%)と 5 コース(3.69%)に集中しています。
さらに「決まり手と 1 着コースが決まった条件での 2・3 着コース」も強く偏ります。
たとえば「まくり差しで 3 コースが 1 着」なら 2 着は 1 コースが 63.4%(n = 2,006)、
「差しで 2 コースが 1 着」なら 2 着は 1 コースが 59.8%(n = 3,389)です。
外の艇が内を差したときは、1 コースの艇が 2 着に残る、という日本語で説明できる構造が
そのまま確率テーブルになります(第 21 章)。

### 4.3 スリット隊形

スタートラインを通過する瞬間の 6 艇の前後関係を**スリット**、その並びを**スリット隊形**と呼びます。
定説では隊形は 3 つに分類されます。

| 隊形 | 特徴 | よくある展開 |
| --- | --- | --- |
| 横一線 | 全艇がほぼ同時にスリットを通過 | イン逃げ or 差し |
| 内凹み | インがスタート遅れ、外が出る | まくり or まくり差し |
| 外凹み | アウトがスタート遅れ | イン逃げ確率 UP |

![スリット隊形 3 分類](/images/boatrace-ml-system/01-slit-formation.png)
<!-- 図: 6 艇を横に並べ、スタートラインに対する前後位置を 3 パターン(横一線 / 内凹み / 外凹み)で描く。艇色は 1 白 2 黒 3 赤 4 青 5 黄 6 緑 -->

この定説を、boatracecsv は結果 CSV の実測 ST から定量的に確かめています
(2025-11-01〜2026-08-09、41,776 レース)。1 コースが他の 5 艇の最先行艇よりどれだけ前に
出ているかを `in_margin`(m)として、隊形を 6 分類した結果の一部です。

| 隊形 | 占有 | 逃げ | まくり系 | 1 着 = 1 コース |
| --- | ---: | ---: | ---: | ---: |
| ほぼ揃い(±0.6m) | 56.7% | 64.0% | 17.8% | 66.4% |
| イン明確先手(+0.6m 以上) | 5.4% | 71.9% | 12.1% | 73.2% |
| イン半艇身遅れ / センター先行 | 17.9% | 36.1% | 40.7% | 39.0% |
| イン大幅遅れ / センター先行 | 3.7% | 8.0% | 70.9% | **9.5%** |

「イン大幅遅れ / センター先行」では 1 コースの 1 着率が **9.5%** まで落ち、7 割がまくり系で決まります。
`in_margin` を連続的に見ると、1 コースが 1.2m(ST 差にして約 0.09 秒)遅れると 1 着率が半分になり、
逆に +0.6m を超えると 73% 前後で飽和します。定説は正しく、スリットは結果を強く規定しています。

ただし、ここで 1.1 の制約を思い出してください。この表の `in_margin` は**本番の実測 ST** から
作ったもので、締切前には存在しません。締切前に手に入る全国平均 ST や展示 ST から組んだスリットでは、
この情報のごく一部しか再現できません。「事後には強い特徴量が事前には使えない」という問題を、
第 19 章で必要精度の逆算まで含めて扱います。

## 5. 場の個性

### 5.1 イン天国と波乱場

1 コースの 1 着率は全国平均で 5 割強ですが、場によって大きく違います。
fun-site `docs/domain.md` にある目安値を挙げます(長期的な目安で、月ごとの実測とはずれます)。

| 分類 | 場 | 1 コース 1 着率の目安 | 特徴 |
| --- | --- | ---: | --- |
| イン天国 | 大村 | 約 65〜70% | 全国 1 位。企画レースが多い |
| | 徳山 | 約 60% | コースが広く、待機行動が短い |
| | 芦屋 | 約 58% | サンライズ V 戦のイン勝率が高い |
| | 下関 | 約 57% | コース形状でイン有利 |
| 波乱場 | 戸田 | 約 43% | 全国最狭の水面(107.5m) |
| | 江戸川 | 約 44% | 唯一の河川コース。風と潮で荒れる |
| | 平和島 | 約 45% | 風向・風速が不安定 |
| | びわこ | 約 47% | 高地で気圧が低く、モーター出力が下がる |

同じ「1 コース」でも、大村と戸田では 1 着率が 20 ポイント以上違います。
枠番 pt や気象 pt が場ごとにテーブルや係数を持つのはこのためで、
第 7 章では強さ pt を作る成分の重み自体を**場別に学習**します。

### 5.2 レース番号による差

もう 1 つ、レース番号による差があります。boatracecsv が 2025-11-01〜2026-07-20 の
39,179 レースで集計した全国の 1 コース 1 着率です。

| レース | 1R | 2R | 3R | 4R | 5R | … | 10R | 11R | 12R |
| --- | ---: | ---: | ---: | ---: | ---: | --- | ---: | ---: | ---: |
| 1 コース 1 着率 | **59.4%** | 47.5% | 47.0% | 47.6% | 54.2% | … | 60.7% | 68.1% | **70.8%** |

2〜4R は約 47% なのに対し、11R・12R は約 70% です。1R が高いのは、1 号艇に A 級選手を置く
「企画レース」の影響です。11R・12R が高い理由は資料に記録されていませんが、後半のレースに
上位の選手が集まりやすいためと考えられます。
場別に見るとレンジはさらに大きく、桐生(場 01)は 2R 30% ⇔ 6R 72%、唐津(場 23)は 7R 38% ⇔ 1R 83% でした。
方向も大きさも場に依存するため、場 × レース番号のテーブル化を試みた予想者(`v6_course`)が
あります。ただしこの予想者は control に回収率で劣り(2026-08-09 退役)、
「データで裏付けられた特徴量でも、予想者として勝つとは限らない」例として第 10 章に出てきます。

## 演習

公開 CSV `https://boatracecsv.github.io/data/results/realtime/YYYY/MM/DD.csv` の 1 か月分を読み、
**場ごと**と**レース番号ごと**の 1 コース 1 着率を集計してください。
5 章の目安値と、自分で集計した 1 か月分がどれくらいずれるかを見るのが目的です。

結果 CSV は 1 レース 1 行で、`1着_艇番` と `1コース_艇番`(実際に 1 コースに入った艇の艇番)を持ちます。
両者が等しい行が「1 コースの艇が 1 着だったレース」です。艇番ではなく**コース**で数えている点が要点で、
前付けで 1 号艇が 1 コースに入らなかったレースも正しく数えられます。

```python:ex01_in_win_rate.py
import calendar
import pandas as pd

BASE = "https://boatracecsv.github.io/data/results/realtime"
NAMES = ("桐生 戸田 江戸川 平和島 多摩川 浜名湖 蒲郡 常滑 津 三国 びわこ 住之江 "
         "尼崎 鳴門 丸亀 児島 宮島 徳山 下関 若松 芦屋 福岡 唐津 大村").split()


def load_month(year: int, month: int) -> pd.DataFrame:
    days = range(1, calendar.monthrange(year, month)[1] + 1)
    frames = []
    for d in days:
        try:
            frames.append(pd.read_csv(f"{BASE}/{year}/{month:02d}/{d:02d}.csv", dtype=str))
        except Exception:  # 未開催日・未取得日はファイルが無い
            pass
    return pd.concat(frames, ignore_index=True)


def in_win_rate(df: pd.DataFrame, key: str) -> pd.DataFrame:
    df = df.dropna(subset=["1着_艇番", "1コース_艇番"])
    win = df["1着_艇番"] == df["1コース_艇番"]  # 1 コースに入った艇が 1 着か
    g = win.groupby(df[key]).agg(["mean", "size"])
    return g.rename(columns={"mean": "1コース1着率", "size": "n"})


df = load_month(2026, 8)
by_stadium = in_win_rate(df, "レース場")
by_stadium.index = [NAMES[int(c) - 1] for c in by_stadium.index]
print(by_stadium.sort_values("1コース1着率", ascending=False).round(3))
print(in_win_rate(df, "レース回").round(3))
```

`dtype=str` で読んでいるのは、`レース場` の先頭ゼロ(`01`)を落とさないためと、艇番を数値に
変換せずそのまま比較するためです。

2026 年 8 月分(31 ファイル、4,798 レース)で実行した結果の一部です。

  並ぶのは目安どおりです。レース番号では 12R が 72.0%、11R が 67.0% で、2〜3R・6R の 44〜48% と
  20 ポイント以上の差があり、5.2 の傾向が 1 か月分でも再現されています
