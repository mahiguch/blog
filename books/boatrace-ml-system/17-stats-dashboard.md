## この章で学ぶこと

| 観点 | 内容 |
| --- | --- |
| ML | 集計軸ごとの回収率を見ると何が分かるか。n が小さいセルを信じない |
| システム | 集計をバッチで前計算する、日別ダイジェストの incremental キャッシュ、予想者ごとの母数 |

## 1. 予想者別の成績ページ

- 通算・月次の的中率と回収率
- 母数は「1〜3 着が揃い、直前買い目が組めたレース」だけ(第 9 章)
- 「もし買ったら」のレース別表示

## 2. 7 軸のブレークダウン

時系列 / 場 / グレード / 買い目点数 / 本命枠番 / 配当帯 / 風速。各セルは n とセットで出し、n < 20 は淡色にする。

## 3. 体験指標

- 平均配当、平均点数、万舟 1 万円あたり(`bigHitPer10kYen`)
- 検出力が足りないので有意差判定はせず、目標値だけ置く

## 4. 集計の実装

- prediction-digest による射影と日別キャッシュ(第 13 章)
- predictor-stats aggregator と predictor-breakdown aggregator
- 簡略版コード(TypeScript、`bigHitPer10kYen` と 1 軸分の集計、50 行)
