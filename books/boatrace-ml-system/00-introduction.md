## この本について

boatrace-fun.net は、ボートレース(競艇)の全レースについて「スタート予想」と「AI による総合評価」を、
締切前に 2 分間隔で更新される静的ページとして配信するファンサイトです。
本書は、このサイトを作って運用する過程で得た知見を、開発の実際の順序に沿ってまとめたものです。

## 対象読者と前提

- Python でデータ処理を書いたことがあるエンジニア
- TypeScript と Astro の基礎(コンポーネント、ビルド)を知っている
- 機械学習は未経験でよい。本書で必要な概念は、その都度実データで説明する
- ボートレースの知識は不要。第 1 章で必要なことをすべて説明する

## この本を読み終えると

- 公開されている 1 レース 1 行の CSV から、自分の特徴量と予測モデルを作れる
- 回収率・的中率・log-loss の違いと、どれで判断すべきかを説明できる
- 予測モデルを Cloud Run Jobs で定期実行し、結果を静的サイトとして配信できる
- 仮説を「予想者」という単位で A/B 実験し、退役させる運用ができる

## 全体アーキテクチャ

3 つの構成要素と、その間を流れるデータを 1 枚の図で示す。

- **boatracecsv**(Python): 公式サイトから収集した CSV を GitHub Pages で配信し、特徴量と強さポイントを計算する
- **fun-site**(TypeScript / Astro): CSV を読んで予想ページを生成し、Cloud Storage + Cloud CDN で配信する
- **GCP**: Cloud Scheduler → Cloud Run Jobs → GCS ミラー → Pub/Sub → Eventarc → Workflows → Cloud Run Job

## 数値の時点について

本書に出てくる回収率・的中率・p 値などの実測値は、特に断りがない限り **2026 年 8 月時点**のものです。
モデルは月次で再学習され、予想者の構成も変わるため、読者が同じ計算を行っても値は一致しません。
