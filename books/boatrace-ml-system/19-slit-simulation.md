## この章で学ぶこと

| 観点 | 内容 |
| --- | --- |
| ML | 事後には強い特徴量が事前には使えない、必要精度の逆算、モンテカルロと分布の校正(Student-t)、撤退ラインの事前設計 |
| システム | Phase 0 で校正が通らなければ実装しない、縮退版だけを出荷する、再挑戦条件を数値で残す |

## 1. 定説「スリットで決まる」は正しい

- 実測 ST から組んだスリット隊形は、強さpt に足して log-loss −0.143。どの特徴量より大きい
- イン大幅遅れ / センター先行では 1 コース勝率が 9.5% まで落ちる

## 2. しかし事前には組めない

- 締切前に取れる ST で組んだスリットは、上限利得の 12% しか回収できない
- 利得の 75% を取るには MAE ≦ 0.016 秒(現行 0.053)。これは分散の 95% 説明に等しく、原理的に届かない
- ST 分散の 56% は「レース共通ショック」で、事前情報では説明できない

## 3. モンテカルロで隊形を分布として出す(slit_sim)

- 選手別 σ を推定し、ST 分布からサンプリングして隊形の確率を出す計画
- 事前に判明していた落とし穴: コース別 ST オフセット、予測偏差の収縮、超過尖度 26.1 の厚い裾

## 4. Phase 0 で不合格

- `in_margin` の相関 0.197(R² 0.039)。隊形 Brier がレース非依存の定数予測に負ける
- 撤退ライン 1・2 も不成立。撤退ライン 3(ST の p25〜p75 帯だけ描く)に縮退
- 帯の校正: Student-t(df 9.14、scale 0.879)で被覆率を合わせる。選手別 σ には意味がある(基準 B は PASS)

## 5. 再挑戦条件

「in_margin の R² が 0.15 を超えたら」と数値で明文化。ネガティブ結果を資産として残す設計書の書き方。

## 6. 簡略版コード

必要精度の逆算(MAE と回収可能利得の関係)と、帯の被覆率チェックを 60 行で示す。
